## Sorgente autorevole

Il repository portfolio contiene i payload italiano e inglese. [Payload italiano](https://github.com/fabiozagaria/fabio-zagaria-portfolio/blob/master/portfolio-angular/scripts/cv-career-ops.json) · [Payload inglese](https://github.com/fabiozagaria/fabio-zagaria-portfolio/blob/master/portfolio-angular/scripts/cv-career-ops.en.json)

Il PDF viene generato con il template Career Ops e con il flusso ufficiale documentato in [`AGENTS.md`](https://github.com/fabiozagaria/fabio-zagaria-portfolio/blob/master/AGENTS.md).

Flusso di aggiornamento:

1. aggiornare il payload Career Ops nel repository portfolio;
2. generare e verificare il PDF A4 a una pagina con Career Ops;
3. sostituire il PDF sorgente del portfolio e sincronizzare qui lo stesso file;
4. verificare che portfolio e repository dedicato distribuiscano PDF identici;
5. **archiviare qui la versione** con `scripts/archivia-cv.sh AAAA-MM-GG "nota" [it|en]`, aggiungere la voce al [CHANGELOG](./CHANGELOG.md) e creare il tag `cv-AAAA-MM-GG`.

**Regola fondamentale: ogni aggiornamento del CV va sempre registrato in questo repository.** La data è quella in cui sono cambiati i contenuti; è la stessa mostrata dal portfolio («CV aggiornato il …»).
